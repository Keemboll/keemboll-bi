Who it's for

Built for BI teams, adopted one developer at a time.

Without a framework, an agent writes DAX and models that work today and break tomorrow: inconsistent names, duplicated measures, forgotten security. Keemboll gives it the rules, and your team gets to write them once.

Teams

Write your conventions once

Put them in TEAM_RULES.md. Every agent and every new colleague applies the same naming, modeling, testing and delivery rules.

Developers

Start alone, in minutes

Install the plugin and your agent stops improvising names, star schemas and standard measures. No setup beyond two commands.

Consultants

Take over a project with a method

Migration, a read-only audit, documentation and handover, reusable on every client project.

Install

Two commands for Claude Code.

You need Claude Code, Git and Python 3.8+.

claude plugin marketplace add keemboll/keemboll-bi
claude plugin install keemboll-powerbi@keemboll-bi

Codex, Gemini, GitHub Copilot, Cursor and others

Clone the repository and let the script copy the skills where your agent reads them.

git clone https://github.com/Keemboll/keemboll-bi
cd keemboll-bi
python scripts/install.py --agent codex --target /path/to/my-bi-project

Supported targets include grok, gemini, copilot, cursor and generic. Details in docs/agents.md.
