# Mockup approval checklist

- [ ] The four questions are written at the top of the mockup and every element serves at least one.
- [ ] The most important KPI is top left; Z reading respected.
- [ ] Every number has a comparison (target, PY) and a unit / period.
- [ ] Every element carries the label of an existing field or appears in "Missing measures".
- [ ] Titles as questions, with the answer when possible.
- [ ] A single accent colour; green / red only for good / bad, paired with a sign.
- [ ] Canvas size, margins, gaps and radii match the design tokens.
- [ ] Toggles and filters planned and named (`Param_...`).
- [ ] 6 to 8 elements at most.
- [ ] Fictitious sample values.
- [ ] "Missing measures" list approved: create them first, or adapt the mockup.
