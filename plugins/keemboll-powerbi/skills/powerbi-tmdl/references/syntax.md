# TMDL — reference examples

The examples are indented with real **tabs**, like the files generated by Power BI Desktop.

## Fact table with measures, columns and partition

```tmdl
table Fact_Sales

	/// Net sales excluding tax. Source: Fact_Sales[NetAmount].
	measure 'Net Sales' = SUM ( Fact_Sales[NetAmount] )
		formatString: $#,##0
		displayFolder: 01 Sales

	/// Gross margin as a % of net sales.
	measure 'Gross Margin %' =
			VAR _sales = [Net Sales]
			RETURN
			    DIVIDE ( [Gross Margin], _sales )
		formatString: 0.0%
		displayFolder: 02 Margin

	column ProductKey
		dataType: int64
		isHidden
		summarizeBy: none
		sourceColumn: ProductKey

	column NetAmount
		dataType: decimal
		formatString: $#,##0.00
		summarizeBy: sum
		sourceColumn: NetAmount

	column OrderDate
		dataType: dateTime
		formatString: yyyy-MM-dd
		summarizeBy: none
		sourceColumn: OrderDate

	partition Fact_Sales = m
		mode: import
		source =
				let
				    Source = Sql.Database(SqlServer, SqlDatabase),
				    Sales = Source{[Schema = "gold", Item = "fact_sales"]}[Data]
				in
				    Sales
```

`SqlServer` and `SqlDatabase` are parameters defined in `expressions.tmdl` (never a hard-coded value in the partition).

## Parameters (expressions.tmdl)

```tmdl
expression SqlServer = "myserver.datawarehouse.fabric.microsoft.com" meta [IsParameterQuery = true, Type = "Text", IsParameterQueryRequired = true]

expression SqlDatabase = "wh_gold" meta [IsParameterQuery = true, Type = "Text", IsParameterQueryRequired = true]
```

## Marked date table

```tmdl
table Dim_Date
	dataCategory: Time

	column Date
		dataType: dateTime
		isKey
		formatString: yyyy-MM-dd
		summarizeBy: none
		sourceColumn: Date

	column Year
		dataType: int64
		summarizeBy: none
		sourceColumn: Year

	column Month
		dataType: string
		summarizeBy: none
		sourceColumn: Month
		sortByColumn: MonthNum

	column MonthNum
		dataType: int64
		isHidden
		summarizeBy: none
		sourceColumn: MonthNum

	hierarchy Calendar
		level Year
			column: Year
		level Month
			column: Month
```

## Relationships (relationships.tmdl)

`fromColumn` = **many** side (fact), `toColumn` = **one** side (dimension).

```tmdl
relationship 8f4b2c1e-0d6a-4f3b-9c55-2a1e7d3b9f10
	fromColumn: Fact_Sales.OrderDate
	toColumn: Dim_Date.Date

relationship 1c9e7a52-6b3d-4e8f-a210-5d4c3b2a1f09
	isActive: false
	fromColumn: Fact_Sales.DeliveryDate
	toColumn: Dim_Date.Date

relationship 5a2d8e7f-3c1b-4a9e-8d6f-7b0c2e4a6d13
	crossFilteringBehavior: bothDirections
	fromColumn: Bridge_CustomerAccount.AccountKey
	toColumn: Dim_Account.AccountKey
```

The name of a relationship is a free identifier (GUID recommended, unique).

## Measure with a dynamic format string

```tmdl
	measure 'Selected Value' = SELECTEDMEASURE ()
		formatStringDefinition = SELECTEDMEASUREFORMATSTRING ()
```

## RLS role (roles/RLS_Region.tmdl)

```tmdl
role RLS_Region
	modelPermission: read

	tablePermission Dim_Store = Dim_Store[Region] = LOOKUPVALUE ( Dim_User[Region], Dim_User[Email], USERPRINCIPALNAME () )
```

## Calculation groups

Safer to **create** them in Power BI Desktop (Modeling → Calculation group) and then edit the items in TMDL. Shape of an item:

```tmdl
		calculationItem YTD = CALCULATE ( SELECTEDMEASURE (), DATESYTD ( Dim_Date[Date] ) )
```

## DAX user-defined function (functions.tmdl)

Requires a model compatibility level of 1702 or higher (`database.tmdl`). Writing and using functions: see `powerbi-dax-udf`. Shape of a declaration, modelled on the Microsoft documentation example:

```tmdl
/// AddTax takes in amount and returns amount including tax
function AddTax =
		(amount : NUMERIC) =>
			amount * 1.1
```

## Verbatim multi-line expressions

To keep the exact whitespace of an expression, wrap it in three backticks:

````tmdl
	measure 'Example' = ```
			VAR _x = 1
			RETURN _x
			```
````
